# **App Name**: Dimes

## Core Features:

- Market Listings: Display list of available markets for betting on future events, filtered by category and popularity.
- Market Details: Individual market pages showing event details, odds, and ability to place buy or sell orders.
- Order Placement: User interface to allow buy/sell orders (limit orders initially), and to show order confirmations.
- Portfolio/Order History: Display the current open orders and the history of filled orders for each user
- Financial predictions: Provide predictions based on a user's submitted prompts regarding financial instruments.  Use LLM tool that checks search indexes to incorporate factual real-world information when providing responses to questions about financial instruments, like: securities, commodities, interest rates, futures, etc. 
- Account Summary: Display current account balance and P&L, allow fund deposits using Stripe.

## Style Guidelines:

- Primary color: Blue (#3498db) for a trustworthy and professional feel, aligning with the requested theme.
- Background color: Light blue (#eaf2ff), a very light, desaturated version of the primary, appropriate to a light scheme.
- Accent color: A slightly different blue, lighter and more saturated (#5dade2), analogous to the primary color, approximately 30 degrees away from the primary hue on the color wheel.
- Body and headline font: 'Inter' sans-serif for a clean, modern, objective appearance.
- Use simple, clear icons to represent market categories and order types.
- Clean, intuitive layout with clear separation of information for markets, orders, and account details.
- Subtle animations for order confirmations and updates to market prices.
